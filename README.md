# APProDub

**One property video, dubbed into 11 Indian languages.**

👉 **Live site:** [https://ayushpal30.github.io/APProDub/](https://ayushpal30.github.io/APProDub/)

APProDub is a landing page for a real estate video dubbing service. One property
video — dubbed into 11 languages — so NRI and out-of-state buyers hear the
project in their own language. Built as a single self-contained HTML file, with
no build step.

---

## What's on the page

| Section | What it does |
|---|---|
| **Problem** | Why a one-language video quietly loses buyers |
| **Solution** | One video, 11 languages, ready in 48 hours |
| **Demo** | Interactive timestamp-based language switcher |
| **Pricing** | Live price calculator + full price table |
| **Reviews** | What clients say |
| **Booking** | WhatsApp booking with a pre-filled message |
